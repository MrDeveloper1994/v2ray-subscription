# V2Ray Subscription

Automatically generated V2Ray/v2rayN subscription.

The source configurations are collected from:

https://github.com/V2RAYCONFIGSPOOL/V2RAY_SUB

The subscription is automatically updated every 2 hours using GitHub Actions.

## v2rayN

Use this URL:

https://raw.githubusercontent.com/YOUR_USERNAME/YOUR_REPOSITORY/main/subscriptions/all-base64.txt

Replace:

YOUR_USERNAME

and

YOUR_REPOSITORY

with your GitHub username and repository name.

## Files

### all.txt

Plain-text subscription containing one configuration per line.

### all-base64.txt

Base64 encoded subscription suitable for v2rayN.

### stats.json

Contains basic statistics about the generated subscription.

## Update schedule

The GitHub Action runs every 2 hours.

It can also be started manually from:

GitHub → Actions → Update V2Ray Subscription → Run workflow
